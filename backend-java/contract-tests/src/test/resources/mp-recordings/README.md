# Gravações do Mercado Pago (Tarefa 3.1)

Mapeamentos do WireMock gravados do **sandbox real** do Mercado Pago, servidos pelo `MercadoPagoFake`.

**Ainda vazio.** A gravação depende das credenciais de teste (`TEST-`) da conta do dono em
`~/.raykookie/mercadopago.env` (ver `docs/mercadopago-cartao-diagnostico.md`, "Ação do dono"). Até lá, a
suíte de contrato cobre só as rotas que não chamam o Mercado Pago.

Quando gravar, registrar aqui: data da gravação, id da conta de teste usada (só o id) e o que foi
mascarado (e-mails, nomes, CPF, ids de conta, `Authorization`).
